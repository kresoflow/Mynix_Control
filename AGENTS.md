## 2. Ключевые фундаментальные инварианты (сводка, детали — в п.1)
- **Multi-Tenancy:** Никогда не добавляй колонку `tenant_id` в доменные модели. Изоляция тенантов работает на уровне схем PostgreSQL. Всегда используй зависимость `get_tenant_session`, которая устанавливает `search_path`.
- **PBAC (Access Control):** Защищай каждый эндпоинт в `router.py` через реестр прав `Perm` (`app/users/permissions.py`): `Depends(require_permission(Perm.<NAME>))`. Сырые нетипизированные строковые права запрещены — см. `02_backend.md §5` за полной процедурой добавления нового права.
- **Единые транзакции:** Любая операция, изменяющая 2+ связанных сущности, обязана выполняться в единой транзакции (`async with session.begin():`).
- **Идемпотентность и ошибки:** Контракт HTTP-статусов при дублях/валидации/PBAC — единый для всего backend, см. `02_backend.md §4`. Не изобретать локальные варианты по модулям.
- **Запрет сырых кнопок и цветов:** Запрещено использовать `ElevatedButton`, `TextButton`, `Colors.*` и `Color(0x...)`. Только компоненты UI Kit (`AppPrimaryButton`, `AppSecondaryButton`) и токены (`AppColors`, `AppRadii`, `AppTextStyles`).
- **State Management:** Запрещено использовать `StatefulWidget` для бизнес-логики. Все состояния управляются через `BLoC` + `Equatable`.
- **Micro-Architecture:** Лимит строк файлов — 200–250 строк (жесткий потолок 300). Запрещены файлы-карлики (<60 строк).

## 3. Стандарт комментирования и эстетики кода (Elite Documentation Standard)
- **Шапка файла:** Python `# ===...===` / Dart `// ===...===` (ровно 80 символов).
- **Сетка разделителей:** 80-символьные линии `# ─── 1. Название ───` / `// ─── 1. Название ───`.
- **Семантические бейджи:** `[ИНВАРИАНТ]`, `[ТРАНЗАКЦИЯ]`, `[БЕЗОПАСНОСТЬ]`, `[UI-KIT]`, `[ФИНАНСЫ]`.

## 4. Agent Skills (`.agents/skills/`)

Операционные плейбуки, которые агент разворачивает по мере необходимости
(активация — по совпадению задачи с `description` в шапке каждого файла):
- [**`backend_architecture`**](./.agents/skills/backend_architecture/SKILL.md) — архитектура бэкенда, транзакции, блокировки with_for_update, защита от MissingGreenlet/N+1, Pydantic DTO, SQL-патчи миграций.
- [**`refactor_bloat`**](./.agents/skills/refactor_bloat/SKILL.md) — декомпозиция разросшихся Flutter/Dart UI-файлов. Не применяется к backend.
- [**`qa_testing_standards`**](./.agents/skills/qa_testing_standards/SKILL.md) — тестирование, линтеры, `scripts/verify_rules.py`, PBAC-проверки, кросс-тенантная изоляция. Применяется к backend и frontend.
