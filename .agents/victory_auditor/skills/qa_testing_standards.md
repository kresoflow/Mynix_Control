# QA & Security Testing Standards

## 1. Линтеры и Гигиена кода
* **Frontend:** После любых изменений UI обязательно запускать `flutter analyze`. В проекте не должно быть ни одного warning (особенно deprecated).
* **Backend:** Соблюдение стандартов архитектуры и отсутствие ошибок импортов (например, запуская сервер или PyTest).

## 2. Тестирование Бэкенда
* Критическая бизнес-логика (например, списание со склада, транзакции чеков) должна быть покрыта тестами.
* Запрещено коммитить код, если тесты или линтер падают.

## 3. Устранение уязвимостей
* Проверяй, что каждый API-роут защищен авторизацией (PBAC / JWT). Никаких публичных эндпоинтов без явного разрешения.
