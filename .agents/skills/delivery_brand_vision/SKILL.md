# Mynix Delivery: Brandbook & Product Vision

This skill acts as the absolute source of truth for the Mynix Delivery App identity. As an AI Agent, you MUST follow these guidelines strictly when making architectural or UI decisions.

## 1. Market Context & Mission
**Context:** Absolute pioneer (First-Mover) in Kulob, Tajikistan. No top-tier IT competitors. Current market uses taxis or manual couriers.
**Mission:** Bring Silicon Valley standards and "highest tier service" to the region. Disrupt the market by providing a flawless, tech-driven Super App.

## 2. Killer Features
1. **True Super App:** Seamless flow between calling a courier, ordering food, and buying from shops/pharmacies.
2. **Speed via Tech:** The fastest delivery powered by algorithms, beating traditional taxi delivery.
3. **Elite Service:** Strict quality control. Couriers are the face of a high-tech company.
4. **Gamification:** Deep loyalty programs and subscriptions to lock in the user base.

## 3. Brand Identity & Art Direction
When building or refactoring UI for Mynix Delivery, enforce these rules:

* **Emotion:** A blend of Premium/Strict (Trust) and Cyber/Tech (Speed/Innovation).
* **Color Palette:** Deep, absorbing dark modes by default. Avoid generic whites unless necessary for contrast. 
* **Glassmorphism:** Use heavy blurring (backdrop filters), semi-transparent surfaces, and subtle borders to create depth and a premium "glass" feel.
* **Accents:** Use highly saturated, neon-like colors (Orange, Purple, Pink) exclusively for Call-to-Action (CTA) buttons or gamification elements. They must slice through the dark background like cyberpunk neon.
* **Typography:** Minimalist, geometric sans-serif fonts. Very clean and highly readable.
* **Cleanliness:** Aggressively avoid clutter. The UI must breathe. If a screen gets too busy, break it down into a Hub model (like we did with the Services Hub).

## 4. Enforcement
If the user requests a feature that clutters the UI or violates this premium/tech identity, you MUST challenge them using the rules defined in this brandbook. Offer a cleaner, more premium alternative.
